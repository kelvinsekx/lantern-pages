Welcome to the C# / .NET learning track.

This track covers the same backend syllabus as the [Node track](/learn/backend/node), from running code and web servers to auth, databases, email and caching, but in C# and ASP.NET Core.

It is written by someone learning .NET in the open, coming from Node and TypeScript. Each article starts from what you would do in Node and shows what changes in .NET, so it works best if you have seen the Node version, but it does not require it.

## How to read this track

- Follow the [syllabus](/learn/backend/dotnet) in order. Stages match the Node track one to one.
- Articles marked as in progress are placeholders for lessons still being written.
- Install the [.NET SDK](https://dotnet.microsoft.com/download) before you start. You can check it with `dotnet --version`.

```bash
$ dotnet --version
$ dotnet new console -n hello
$ cd hello && dotnet run
```
